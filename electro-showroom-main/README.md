# Electro Prime Showroom

Build a premium interactive technology e-commerce website called ELECTRO PRIME.

Electro Prime sells:

Laptops

Smartphones

Tablets

Monitors

Keyboards

Mice

Headphones

Earbuds

Chargers

Power banks

Cables

Laptop accessories

Phone accessories

Storage devices

Computer components

Gaming accessories

Other consumer electronics

The website should feel like:

Luxury technology showroom × futuristic product laboratory × premium e-commerce × cinematic interactive experience.

This should NOT look like a generic electronics store, Amazon clone, Shopify template, or boring product grid.

CORE VISUAL DIRECTION

Create a sophisticated, modern technology aesthetic.

Think:

Apple-level product presentation + futuristic technology showroom + cinematic product advertising.

The design should feel:

premium

futuristic

precise

technological

clean

immersive

responsive

expensive

Do NOT rely on cheesy neon effects, excessive gradients, excessive glassmorphism, or random glowing borders.

The visual language should communicate precision and engineering.

Use strong typography, large product photography, dramatic whitespace, carefully controlled contrast and sophisticated layouts.

HOMEPAGE HERO

The hero should immediately communicate that Electro Prime is a premium technology retailer.

Do NOT make a standard:

"Welcome to Electro Prime — Shop Now"

banner.

Instead create an immersive product presentation.

Feature a major product such as:

premium laptop

flagship smartphone

gaming laptop

monitor

or another flagship device.

The product should occupy a large portion of the screen.

Allow subtle mouse interaction:

perspective rotation

depth movement

lighting response

layered background movement

product tilt

subtle camera movement

The product should feel like a physical object sitting inside the interface.

The interaction must remain subtle and premium.

3D PRODUCT EXPERIENCE

Interactive 3D is one of the major features of the website.

Where actual 3D models are available, use:

Three.js

React Three Fiber

Drei

Allow users to:

rotate products

inspect different angles

zoom

interact with product surfaces

switch configurations

explore details

For example, a laptop could rotate from:

FRONT → SIDE → BACK

while showing contextual information.

A smartphone could rotate to reveal:

camera system

frame

ports

rear design

A mouse/headphone/product accessory could similarly be presented as an interactive object.

If no actual 3D model exists, create convincing interactive product presentations using high-quality images, layered depth and CSS 3D transforms.

Do NOT invent fake 3D assets that look terrible.

SCROLL-DRIVEN EXPERIENCE

Scrolling should be a major part of the interaction.

Do NOT simply make every section:

fade in
translate upward
fade in
translate upward


I want the website to transform as the user scrolls.

Use:

sticky sections

pinned scenes

scroll timelines

clip-path

image masks

CSS 3D transforms

perspective

layered elements

product scaling

image cropping

controlled scroll velocity

horizontal product sequences where appropriate

The user should sometimes feel like:

"The product stayed in place while the entire environment changed around it."

HERO SCROLL TRANSFORMATION

For example:

A laptop begins centered in the hero.

As the user scrolls:

The laptop remains visually anchored.

The camera perspective subtly changes.

The background transforms.

Product specifications appear around it.

Text moves around the product.

The laptop rotates slightly.

A second product or accessory enters the scene.

The composition transitions into the next section.

The result should feel like the user is exploring the product, not merely scrolling past an advertisement.

PRODUCT CATEGORY EXPERIENCE

Create major categories:

LAPTOPS
PHONES
TABLETS
COMPUTERS
MONITORS
ACCESSORIES
GAMING
AUDIO

Do not present these as boring cards.

Each category should feel like a separate chapter in the showroom.

Example:

LAPTOPS

A large laptop dominates the screen.

Scrolling can:

rotate the laptop

change the camera angle

reveal specifications

introduce another laptop

transition between product families

reveal a product collection

Then transition naturally into:

SMARTPHONES

The laptop composition transforms into a phone-focused composition.

The transition should feel continuous rather than like one webpage section ending and another beginning.

PRODUCT REVEALS

Products should appear in interesting ways.

Use:

masked reveals

scale transitions

3D perspective

image cropping

layered entrances

objects emerging behind other objects

products moving through depth

subtle rotations

composition changes

Some products should feel like they materialize into the scene.

Avoid making every product use the same animation.

PRODUCT COLLECTION

The store must still be highly usable.

Products should include:

product image

name

price

discount where applicable

rating

specifications

available colors

storage/RAM options where applicable

quick view

wishlist

add to cart

But don't make the entire website a rigid grid.

Mix:

large featured products

horizontal product rails

editorial product layouts

asymmetric grids

interactive product cards

comparison sections

The e-commerce functionality must remain obvious.

LAPTOP EXPERIENCE

Laptops should receive special treatment.

Create a premium laptop section where users can explore:

screen

keyboard

ports

thickness

hinge

rear

specifications

When possible, use interactive 3D.

Display contextual information as the laptop rotates.

For example:

Laptop rotates → ports highlighted → specification appears.

Laptop rotates → display highlighted → screen information appears.

This should feel like a digital product showroom.

SMARTPHONE EXPERIENCE

Create an immersive smartphone section.

Show:

front

rear

camera system

side profile

colors

storage variants

Allow users to switch colors and configurations with smooth transitions.

The phone can rotate in 3D while the surrounding information changes.

GAMING SECTION

Create a more energetic section for:

gaming laptops

keyboards

gaming mice

headsets

controllers

monitors

This section can have stronger motion than the rest of the site.

Still keep it sophisticated.

Avoid turning it into a generic RGB gaming website.

ACCESSORIES

Create a visually interesting accessories section.

Products can enter the scene in layers:

Keyboard
↓
Mouse
↓
Headphones
↓
Mousepad
↓
Webcam

Create the feeling of assembling a complete workstation.

The user can interact with each product.

PRODUCT DETAIL PAGE

Make product pages feel like interactive digital showrooms.

Include:

large product presentation

interactive gallery

3D viewer where available

product name

price

rating

specifications

variants

color selection

storage/RAM configuration

quantity

Add to Cart

Buy Now

Wishlist

shipping information

warranty information

related products

Use sophisticated transitions between product images.

Do not instantly swap images.

Use:

current image → mask/scale/3D transition → next image.

PRODUCT COMPARISON

Technology shoppers care about specifications.

Create an elegant comparison experience.

Allow users to compare products such as:

Laptop A vs Laptop B

or:

Phone A vs Phone B.

Show important specifications clearly:

CPU

GPU

RAM

Storage

Display

Battery

Camera

Ports

Weight

Connectivity

The comparison interface should still fit the premium design.

NAVIGATION

Create a minimal premium navigation.

Possible structure:

ELECTRO PRIME

Laptops
Phones
Tablets
Computers
Monitors
Accessories
Gaming

Then:

Search
Account
Wishlist
Cart

Create an immersive mega-menu.

When opened, it can become a large full-width navigation panel containing:

categories

featured products

product imagery

collections

quick links

Use smooth transitions rather than a basic dropdown.

SEARCH

Search should feel powerful.

Allow users to search for:

"Lenovo laptop"

"16GB RAM laptop"

"iPhone"

"wireless mouse"

"gaming headset"

etc.

Create an elegant search overlay with animated results.

CART

The cart should feel like part of the same experience.

Use a smooth slide-in cart or immersive cart panel.

Show:

product

variant

quantity

price

subtotal

remove

checkout

Use subtle transitions when products enter or leave the cart.

MOTION SYSTEM

Create a coherent motion language.

Hero:
3D depth + subtle product interaction

Product sections:
scroll-driven transformations

Category sections:
cinematic transitions

Product cards:
hover perspective + image transitions

Product pages:
interactive 3D/product galleries

Navigation:
smooth full-screen transitions

Cart:
fluid slide/scale transition

Text:
restrained movement

Do NOT animate everything at once.

The motion should communicate the physical qualities of technology.

TECHNOLOGY STACK

If this is a React project, prefer:

React

Three.js

React Three Fiber

Drei

GSAP

ScrollTrigger

Use CSS 3D transforms when WebGL is unnecessary.

Do NOT use WebGL just because it sounds impressive.

Use the simplest technology capable of producing the desired effect.

PERFORMANCE

Performance is extremely important.

Electronics stores may contain many large product images and potentially heavy 3D models.

Implement:

lazy loading

responsive images

compressed assets

optimized textures

lazy-loaded 3D scenes

GPU-friendly animations

animation cleanup

visibility detection

efficient React rendering

Do not run expensive 3D scenes when they aren't visible.

Provide sensible fallbacks for weaker devices.

Respect:

prefers-reduced-motion

MOBILE

Mobile must be treated as its own experience.

Do not simply shrink the desktop site.

On mobile:

simplify heavy 3D

reduce simultaneous effects

preserve important product interactions

maintain fast shopping

make buttons easy to use

keep navigation accessible

The experience should still feel premium.

DESIGN RULE

The website should NEVER feel like:

"A normal electronics store with animations added afterward."

Instead it should feel like:

"I walked into the Electro Prime digital showroom."

The products are the stars.

The interface should make technology feel tangible, premium and exciting.

IMPLEMENTATION PROCESS

Before coding:

Inspect the project structure.

Establish the design system.

Establish the product data model.

Plan the page architecture.

Plan the motion system.

Identify which sections require 3D.

Identify which sections can use CSS/GSAP.

Build the static foundation.

Add the motion system.

Add 3D experiences.

Test desktop.

Test mobile.

Optimize performance.

Do not build a generic store first and randomly add animations afterward.

The architecture should be designed around the interactive experience from the beginning.

FINAL EXPERIENCE

When someone opens Electro Prime, the immediate reaction should be:

"Damn, this feels like a technology showroom."

When they scroll:

"The website is transforming around the products."

When they interact with a product:

"I can actually explore this thing."

And when they want to buy:

"Everything is still simple and easy to use."

Create a polished, production-quality frontend that combines premium technology retail, cinematic motion, interactive 3D and practical e-commerce UX.
